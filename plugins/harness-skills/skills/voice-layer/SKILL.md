# Voice Layer

管三件事：**解釋的骨架**、**術語密度**、**語氣**。不改任何數字、結果、劑量或出處。

> （選用）同一套規則也可以寫成 output style 讓對話常駐套用。本 skill 用在**長文件**上——需要明確判定分層、或同一份內容要出多個版本時。

骨架排第一。**把術語換成白話救不了結構壞掉的解釋**：在讀者最熟的領域裡（他本行的那些術語）照樣會看不懂，因為那裡的問題從來就不是詞太難。

## 一、解釋骨架（結構層，所有術語層都適用，包含 T1）

看不懂通常是結構問題：一次丟太多新東西，或者先把 A 講完再把 B 講完，然後要讀者自己去對照。

### 難概念的四步，順序不能換

1. **一句話先給答案。** 「是 A」「兩個都對，差在 X」「這題問錯了，真正的分岔是 Y」。不暖身、不先鋪定義。
2. **先架設定，再給場景。** 講清楚四件事：**什麼在變、什麼固定住、我們事先已經知道什麼、這個例子要證明什麼**。缺任何一件，例子就是半個場景，對方沒有立足點只能被拖著走。設定講完才給真的物件、真的數字、真的實驗。形式定義擺在具體**之後**。
3. **反差點：什麼情況下 A 和 B 會給出不同答案。** 這是解釋「A 跟 B 差在哪」唯一有效的做法。
4. **所以呢：這個差別會改變讀者哪個動作。** 換哪個分析、信不信這個結果、要不要回診、要不要重跑。

### 筆記專用的四條

- **每節開頭一行「這節在回答什麼問題」。** 沒有這一行，讀者不知道自己在讀什麼、可以跳過什麼。
- **「A vs B」不要寫成 `## A` 加 `## B` 兩節。** 那是把對照這一步丟給讀者，而那正是他卡住的地方。改成一節「差在哪」＋ 一個兩邊給出不同答案的案例。
- **一節一個新概念。** 要理解 X 得先懂 Y，就讓 Y 自己佔一節，不要在講 X 的段落裡「順便補充一下」。
- **承重的術語一律當場定義，T1 也不例外。** 判準：這個詞讀者如果理解錯了，後面整段會不會白講？會 → 定義它。T1 免除的是讀者天天在用的基礎術語，不是這份文件的關鍵字。

**比喻要連動作一起給。** 用了「容器」就得說什麼叫「裝進去」，用了「切」就得說切的是什麼。只給名詞不給動作，對方會以為自己懂了，然後在你用那個動作做推論時整段卡住。比喻裡的每個動作都要能換回真實操作（「裝到多少」＝把點垂直投影到平面、算影子保留了幾成）。

**讀到的和推出來的要分開講。** 「這篇說 X」跟「我從搜尋結果推測 X」是兩種不同強度的話，寫成同一種語氣就是在冒充出處。沒讀內文只讀摘要就說「這篇講了 Y」也算——那是推測，要嘛去讀，要嘛標明只看了摘要。引用具體術語對應、數字或主張之前，先確認那個詞真的出現在那篇裡。

**數字旁邊要有比較基準。** 讀者要拿來下判斷的數字，旁邊放一個能比的東西：參考範圍、上一次的值、或換算成倍數／比例。「血紅素 11.8」讀者看不出高低；「血紅素 11.8 g/dL（檢驗單參考下限 12，上次 12.5）」才看得出偏低而且在往下走。結論裡的「偏高」「改善」「差很多」，每一個都要指得回旁邊那個數字。

**先讓對方看到那個東西，再給它名字。** 在曲線還沒畫出來之前就講「膝蓋」，那個字沒有東西可以指。順序是：建構 → 命名 → 使用。
- **對話可以停下來問，筆記不行**，所以把下一層寫成明確的**待答清單**（「還沒回答：① … ② …」），而不是一次全部塞進正文。

### 八種常犯的爛結構

- **平行鋪陳**：A 講完再講 B，對照留給讀者做
- **定義先行**：從形式定義開始，具體例子擺最後或根本沒有
- **術語連鎖**：用另一個沒解釋的術語解釋這個術語
- **補完主義**：第一輪就把例外、邊界條件、反例全塞進去
- **換圖不宣告**：同一份資料有好幾種畫法（時間曲線／點雲／矩陣／頻譜），中途換一張而沒說「我現在換一張圖看」。對方以為還在原本那張裡，整段就崩了
- **丟掉共同語言**：前面已經跟對方一起建好一套講法（他點頭的那些比喻、他自己用過的詞），後面卻換回術語、符號或抽象標籤重講一次。這比丟新術語更糟——共同語言是唯一驗證過對方真的懂的東西，換掉它等於把前面幾輪的成果全部作廢。**建好的講法要一路用到底，除非對方自己換掉它。**
- **結論並排**：推論的幾步寫成條列，中間的「因為／所以／但是」留給讀者自己補。測法：把條列唸成一段話，要自己加「所以」才接得起來 → 把那個連接詞寫出來，改回段落
- **三個新概念一起丟**

**收束段不准出現新東西。** 「差別在哪」「所以呢」「總結」這種段落是對方最放鬆的地方，在那裡丟一個新概念或新的畫法，殺傷力比在正文丟大。收束只能用前面已經出現過的詞。

## 二、先判定讀者，再判定層級

順序不能顛倒。層級跟著**誰會讀這份東西**走，不是跟著誰寫走。

| 讀者 | 層級 |
|---|---|
| 醫師、審稿人、口試委員、同領域研究者 | **T1** |
| 使用者自己 | 看下面的領域表 |
| 家人、長輩、非技術同事、客戶 | **T3** |

一份文件有兩種讀者時，**分節標明哪一節給誰**，不要混在同一段。混在一起的下場是兩邊都讀得很累。

## 三、三層

| 層 | 術語 | 句子 |
|---|---|---|
| **T1 專業** | 直接用，不解釋 | 可長、可密、可用符號與公式 |
| **T2 中間** | 用，但第一次出現補一行白話 | 一句一個重點 |
| **T3 白話** | 不用；非用不可就當場翻成生活講法 | 短句、主動語態、一句一個動作 |

**T3 不是把內容變淺**，是把同樣的內容換成不需要背景知識的說法。刪資訊不叫 T3。

**術語層管詞，骨架管結構，兩者獨立。** T1 的文件照樣要走第一節的四步，承重術語照樣要定義。

T3 的術語處理有三種寫法，照這個順序挑：

1. 完全換掉：「顳動脈」→「太陽穴旁邊那條血管」
2. 保留術語＋緊接白話：「巨細胞動脈炎（太陽穴血管發炎，會影響視力）」
3. 只在需要對外溝通時保留原詞：「這個病的名字是巨細胞動脈炎，跟醫師講這五個字就好」

第 3 種用在**讀者需要拿這個詞去跟別人溝通**的時候（掛號、買藥、查資料）。

## 四、使用者的領域預設（產出物給他本人看時）

（選用）在這裡列出你自己的領域分層，例如：

**T1**：你的本行與天天在用的工具鏈（例：物理、ML／Python、統計方法）

**T2**：熟悉但非本行的鄰近領域（例：產業分析、金融名詞、談判與人際方法論）

**T3**：完全外行的領域（例：醫學臨床、藥理、檢驗數值；法律、行政制度；財會、稅務、保險）

沒列到的用 T2。同一份文件裡不同段落可以是不同層，按那一段的主題判定。

使用者說「T1」「用術語就好」「講白話」「嬰兒版」等，直接覆蓋以上全部。

使用者說「看不懂」「太複雜」時，**先重搭骨架，不要只降術語層**——降層改的是詞，而他卡住的通常是結構。

## 五、語言規則

完整清單在 `references/vault/AI寫作破綻清單_中文版_Signs-of-AI-Writing.md`。**不要在這裡複製一份**，需要細節時去讀那個檔。常駐守六條：

1. 能用「是」就用「是」，不寫「扮演…的角色」「具備」「可視為」
2. 不用否定式排比（「不僅…更…」「不只是…而是…」）
3. 不湊三項——只有兩點就寫兩點
4. 同一個東西從頭到尾用同一個詞，不做同義詞輪換
5. 砍掉沒有數字的程度副詞與評價尾巴
6. 不用萬用開場與收束（「值得注意的是」「綜上所述」）

## 六、排版密度（分場合）

**健康紀錄、就診文件、實務紀錄、清單、報告**：

- 粗體不超過全文約 10%。粗體標「這一行是重點」，不是標「這個詞很重要」
- 連續 3 行內最多 1 個 callout
- 每節最多 1 個 emoji
- 「**粗體標題**：說明」式條列連續不超過 5 條

**長篇章節與學習筆記不套用以上上限**。（選用）若你有自己的寫作／排版規範，放在 `notes/writing-style.md` 並依它走。

## 七、不要矯枉過正

以下不是 AI 味，砍掉會變成另一種假：

- 證據不足時的 hedging（「結果顯示」而非「結果證明」）是正確的科學語言
- 動作者不重要時的被動語態
- **專有名詞原文、公式、符號、引用、數字、劑量一律原樣保留**
- 破折號可以用，反對的是密度不是存在。學術稿件與投稿文件同理：`academic-humanizer` 的判準也是「對照作者自己的基準線砍多的」，不是全面禁用——兩個 skill 對破折號的規則一致，不會互相改回去
- 句長變化要有修辭理由，機械地每節塞兩句短句是雜亂不是人味

## 八、流程

1. **判定讀者與層級**，一句話講出來（「這份給醫師，T1」）。讀者不明就問，不要猜。
2. **搭骨架**：每個難概念走四步；「A vs B」的段落找出反差案例；一節一個新概念。
3. **寫或改**。改稿時先列出要動的地方與理由，不要直接覆蓋。
4. **自查**（見下）。
5. **數一次粗體佔比**（適用場合才數）。

### 自查用數的，不用感覺

不要問「我覺得這樣夠清楚嗎」——知識詛咒的定義就是這個自評會失效，寫的人測不出自己跳掉了哪一步。改成六個可以數的檢查：

1. **數新名詞**：一段裡有幾個沒解釋過的術語？超過一個 → 砍。剩下那個是不是承重術語？是 → 當場定義。
2. **檢查設定**：每個難概念有沒有配一個真的場景？那個場景有沒有講清楚什麼在變、什麼固定、要證明什麼？缺任一項 → 那是半個場景。
3. **找反差點**：有「A 還是 B」「A 跟 B 差在哪」的段落嗎？有沒有一個兩邊給出不同答案的例子？沒有 → 這題還沒回答完。
4. **點名共同語言**：前面幾輪建立、對方已經點頭的講法，這段有沒有用？換成符號、公式或抽象標籤了嗎？換了 → 換回來。
5. **看有沒有「所以呢」**：這段會改變讀者的哪個動作？講不出來 → 這段可能不用寫。
6. **數字找基準**：每個要讀者據以判斷的數字，旁邊有沒有參考範圍、前次值或比例？沒有 → 補上；真的找不到基準，就寫明「沒有可比的基準」，不要讓讀者自己猜高低。

一份內容要出多個版本時，**每個版本各自完整**，不要寫成「詳見專業版」——需要白話版的讀者不會去翻專業版。
