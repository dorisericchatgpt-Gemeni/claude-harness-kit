# AI 寫作破綻清單（中文版）

> [!note] 出處與授權
> 改編自英文維基百科 [Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)（原文依 CC BY-SA 4.0 授權）。**本檔依 CC BY-SA 4.0 釋出**（https://creativecommons.org/licenses/by-sa/4.0/）；本檔為改編作品，語言層重新映射成繁體中文並增補內容。

> [!info] 這是什麼
> 改編自英文維基百科 [Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)（WikiProject AI Cleanup 累積約 15,000 字、清理過 10,000+ 篇條目的實測目錄）。
>
> **不是翻譯。** 英文的詞彙破綻（delve、tapestry、pivotal）在中文裡不存在，我把「語言層」整層重新映射成繁中對應；「格式層」與「結構層」跨語言通用，直接沿用並補上**學習筆記**情境的版本。
>
> **用途**：寫完 learning note / 章節 / 論文段落後自查，或叫 AI 改稿時當禁用清單貼給它。

> [!warning] 先讀這條再往下（原文自己的警告）
> 這份清單是**描述性的，不是規範性的**。原頁明講：「這些模式只是問題的**潛在徵兆**，不是問題本身。」
>
> 三個推論：
> 1. **人也會這樣寫**，命中不等於是 AI 寫的。
> 2. **逐條照改只是讓偵測變難**，沒解決底層問題——底層問題是「涵蓋了一個主題但沒真的投入」。
> 3. 人類判讀 AI 文本的準確率**接近隨機**，偵測工具錯誤率也不低。所以這清單的價值在**改自己的稿**，不在指控別人。

## 第一層：內容（最難修，但最值錢）

這層是「說了什麼」的問題，不是「怎麼說」。修這層要重寫，不是換詞。

### 1.1 意義膨脹（significance inflation）

把平凡的東西講成劃時代。原文的診斷很準：LLM **regress to the mean**，會把具體事實換成通用的正面語言（「第一個火車連結器的發明人」→「革命性的產業巨擘」）。

**中文常見句式：**

| 破綻 | 為什麼是破綻 |
|---|---|
| 標誌著…的重要里程碑 | 誰認定的？拿什麼比較出「重要」？ |
| 開啟了…的新篇章 / 新紀元 | 純修辭，零資訊 |
| 為…奠定了堅實的基礎 | 「奠定基礎」是事後敘事，當下不可驗證 |
| 具有重要的意義 / 至關重要 | 對誰重要？多重要？ |
| 在…領域佔有舉足輕重的地位 | 舉不出排名就是空話 |
| 展現了…的深厚底蘊 | 觀光文宣語言 |

**自查**：把這句刪掉，讀者少知道什麼事？答「沒少」→ 刪。

### 1.2 評價尾巴（英文的 participle tail，中文對應）

英文是 `..., highlighting X` / `..., emphasizing Y` 掛在句尾假裝分析。中文的對應是**掛在句尾的評價子句**：

- 「…，體現了其獨特的價值。」
- 「…，展現出強大的適應能力。」
- 「…，進而推動了整體發展。」
- 「…，為後續研究提供了寶貴的參考。」
- 「…，反映出該領域的蓬勃發展。」

**特徵**：這些尾巴沒有出處、沒有數據，是**沒署名的意見偽裝成描述**。原文歸類為「原創研究」等級的違規。

**改法**：要嘛給出處與數字，要嘛整句砍掉。

### 1.3 宣傳語（puffery）

原文列的高頻詞：vibrant、nestled、rich cultural heritage、profound、groundbreaking、commitment to、diverse array。**同一套詞會出現在完全不相干的主題上**——這才是破綻，不是單詞本身。

**中文對應**：豐富的、多元的、蓬勃的、卓越的、深厚的、強大的、全面的、精準的、賦能、助力、打造、淋漓盡致。

### 1.4 模糊歸屬（vague attribution）

- 「研究顯示…」「相關研究指出…」（沒說哪篇）
- 「業界普遍認為…」「專家認為…」（沒說誰）
- 「一般而言…」「眾所周知…」
- 兩個來源就寫成「學界共識」

這條跟論文寫作的論證鏈要求直接衝突：**每個 claim 要能指到 figure 或數據**。

### 1.5 先低調再膨脹（over-hedging 後接意義宣稱）

原文的例子很經典：「雖然它的應用有限，但它對早期航空工程的整體歷史有所貢獻」——先承認冷門，再硬拉一個宏大意義。

中文版：「雖然目前尚無定論，但這一方向無疑具有廣闊的前景。」

## 第二層：語言（重新映射成中文，最好修）

### 2.1 中文 AI 詞彙表（命中密度高就有問題）

> [!tip] 用法
> 單一個詞出現一次不算什麼。**破綻是密度**——一篇裡出現五六個以上就有味道了。

**評述類**
值得注意的是 / 值得一提的是 / 需要指出的是 / 更重要的是 / 事實上 / 換言之

**深度類**
深入探討 / 深入剖析 / 深入淺出 / 進一步 / 更進一步 / 全面性地 / 系統性地

**核心類**
關鍵在於 / 核心在於 / 本質上 / 究其根本 / 歸根結底

**角色類**
扮演著重要的角色 / 發揮著關鍵作用 / 佔據著重要地位

**收束類**
綜上所述 / 總的來說 / 總而言之 / 由此可見 / 不難看出

**開場類**
隨著…的不斷發展 / 在…的背景下 / 近年來，…日益受到關注 / 從…的角度來看

**關係類**
相輔相成 / 息息相關 / 密不可分 / 相得益彰 / 環環相扣

**沒有數字的程度副詞**
顯著地 / 大幅 / 有效地 / 極大地 / 充分地

### 2.2 迴避「是」與「有」（原文的 copula avoidance，中文完全成立）

| AI 慣用 | 直接講 |
|---|---|
| 作為一種…，X 具備… | X 是… |
| X 扮演…的角色 | X 是… |
| X 可視為 / 堪稱 | X 是… |
| X 具備 / 蘊含 / 擁有 | X 有… |
| X 呈現出…的特性 | X 很… |

**原則**：能用「是」就用「是」。繞開「是」通常是為了讓句子看起來比內容更厚。

### 2.3 否定式排比（negative parallelism）

英文 "not just X, but Y"。中文的三個變體：

- 「不僅…更…」
- 「不只是…而是…」
- 「與其說是…不如說是…」

原文標記這是最強的單一破綻之一。中文尤其嚴重，因為它讀起來很像「有洞見」，實際上只是把一件事講兩遍。

### 2.4 三項排比（rule of three）

三個並列的四字詞、三個頓號串起來的名詞、三段式的「首先…其次…最後…」。

**問題不是「三」，是「湊三」**——實際上只有兩點，硬生一個湊對稱。

### 2.5 同義詞輪換（elegant variation）

原文舉的例子：同一個概念在一段裡被寫成 constraints / obstacles / confines / norms 四種說法。

中文版：限制 → 束縛 → 桎梏 → 框架 → 制約，全部指同一件事。

**技術寫作要反過來：同一個東西從頭到尾用同一個詞。** 換詞會讓讀者以為你在講不同的東西。

## 第三層：格式（跨語言通用，直接照抄原文）

原文把格式獨立成一整類，這點很重要——**排版破綻跟用詞破綻一樣強**。

- [ ] **標題 title case**（英文標題每個實詞大寫）→ 中文版對應：每個標題長度、句式一模一樣
- [ ] **過度粗體**：把選定術語**每一次**出現都加粗，像簡報而不像文章
- [ ] **「粗體標題：說明」式條列**：`- **重型旋轉鋸**：適用於磁磚、金屬…` ← 這是最容易辨識的 LLM 版面
- [ ] **破折號（em dash）過量**：拿來代替句號或冒號，假裝高級
- [ ] **彎引號 / 彎撇號**：某些 LLM 輸出的殘留
- [ ] **括號補充句過多**：模仿學術腔但模仿錯了
- [ ] **跳過標題層級**（H2 直接跳 H4）
- [ ] **引用殘留物**：`oaicite`、`contentReference`、`turn0search0`（ChatGPT）、`[cite: 1]`、`[span_1]`（Gemini）；壞掉的外部連結、無效 DOI、宣告了但正文沒用到的參考文獻

## 第四層：結構（原文有，但學習筆記情境要另外補）

### 4.1 公式化結尾段（原文的 "challenges and future prospects" 模板）

原文抓到的模板：「儘管有 [優點]，[主題] 仍面臨 [挑戰清單] 等挑戰。儘管如此，[主題] 仍持續 [正面結果]。」

**這個結構會原封不動出現在毫不相干的主題上**——碳氫經濟、都市規劃、電視台、熱電材料，句型完全一樣。

中文筆記版的對應：每章結尾都有一段「小結 / 限制與未來方向」，而且句式一致。

### 4.2 學習筆記特有的結構破綻（不在原文，本地補充）

- [ ] **每章長度雷同**——真人筆記形狀是歪的，卡住的那節佔一半篇幅
- [ ] **每章骨架同構**——關鍵字 → 主體 → 相關章節 → 資料來源 → 自測，一路重複
- [ ] **假完整性：沒有一個開放的洞**——每個問題都收得漂漂亮亮，沒有 `待查`、沒有「這裡我沒想通」
- [ ] **全覆蓋、輕重不分**——每個子題都寫到，但沒有哪一段看得出作者真的在乎
- [ ] **沒有修訂痕跡**——真人筆記會累積「2026-07-14 重看，發現上面寫錯了」，AI 產出永遠是乾淨的第一版
- [ ] **從「已經懂的人」的位置寫**——這是 learning note 最根本的破綻。筆記應該記錄**學的過程**（卡在哪、把什麼跟什麼搞混了、後來怎麼想通），而不是把結論攤平成教科書

## 第五層：指令與規範文件（判準跟散文不同）

前四層管的是**散文**——論文、筆記、章節。指令檔（CLAUDE.md、AGENTS.md、`_*規範.md`、skill）的失敗模式不一樣：它不是讀起來假，而是**同一條規則有兩個家**、寫了但沒人找得到、或內容早就過期卻沒人發現。

四條散文清單沒有、但指令檔特別容易犯的：

- [ ] **同一規則出現在兩個檔案**——grep 剛寫完的特徵句，命中別處就砍一邊留連結。兩份會漂移，而且沒人知道哪份是現行的。
- [ ] **敘述歷史**：「原本…改成」「之前是」「不再使用」。寫現況；沿革丟給 git、Agent Note 或 postmortem。
- [ ] **狀態註記**：「已完成！」「待實作」「future:」。狀態爛得比什麼都快，讓目錄結構自己說。
- [ ] **手抄一份可以自動列出來的清單**（有哪些 skill、有哪些檔案、跑過哪些測試）。

第三層的「過度粗體」在指令檔裡也常叫 emphasis inflation，是同一條。

## 反向清單：不要過度矯正

> [!danger] 修過頭會變成另一種假
> 以下每一條都有人踩過。

1. **句長變異（burstiness）要有修辭理由。**
   長短句交錯確實是人類特徵（AI 偵測器的正式指標之一），但人類的變化來自**強調、壓縮、岔題、自我打斷**——變化背後有意圖。機械地「每節塞兩句短句」讀起來是雜亂，不是人味。

2. **該有的 hedging 不要砍。**
   證據不足時寫「結果**顯示**」而不是「結果**證明**」是正確的科學語言，不是 AI 味。砍掉會變成過度宣稱。

3. **被動語態沒問題**，當動作者不重要時（「樣本以總蛋白量正規化」）。

4. **專有名詞、公式、符號、引用一律原樣保留。** 去味絕不能動任何數字、結果或出處。

5. **破折號可以用**，只是不要拿來代替所有標點。原文反對的是密度，不是存在。

6. **「這份清單本身不是禁令」**——原文原話：這不是對特定字詞或標點的封殺令。

## 三十秒版自查（改稿時只跑這個）

1. 有沒有句子刪掉後讀者一無所失？（意義膨脹）
2. 有沒有「，體現了 / 展現出 / 進而…」的評價尾巴沒有出處？
3. 「值得注意的是 / 不僅…更… / 綜上所述」出現幾次？超過兩次就砍。
4. 條列是不是「**粗體**：說明」的整齊格式？改成散文。
5. 有沒有因果鏈被壓成並列條列？（因為→所以→但是 一律寫成段落）
6. 全篇有沒有**一個**開放的問題、一句「我沒想通」？沒有 → 這不是學習筆記。
