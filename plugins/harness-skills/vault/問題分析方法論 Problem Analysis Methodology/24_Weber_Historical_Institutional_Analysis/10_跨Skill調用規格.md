# 韋伯式歷史制度分析法——跨 Skill 調用規格

**所屬分支：** 00_教學大綱總覽  
**核心程序：** [[02_韋伯式經濟史分析方法]]  
**當代操作化：** [[../23_Weber_Institutional_Economic_Analysis|23 Weber 制度經濟分析]]
**上一章：** 00_教學大綱總覽 ｜ **下一章：** [[02_韋伯式經濟史分析方法]]

> [!important] 方法契約
> 當任務是在解釋制度、產業、組織或技術秩序的**形成、分岔、持續與崩解**時，不能只列因素或摘要歷史；必須產出可比較的制度維度、行動者機制、因果角色、反例／對照與來源層級。

## 一、觸發條件

符合任一項即可考慮調用：

1. 使用者問「為什麼同一政策／市場／技術，在不同地方結果不同？」
2. 問題涉及國家、法律、產權、勞動、技術、市場、企業邊界、宗教或組織文化的交互作用。
3. 需要區分個人行為、組織激勵與制度機會結構。
4. 需要解釋某種活動何時從偶發事件變成持續、可核算、自我再生產的秩序。
5. 有「技術造成 X」「市場必然帶來 Y」「文化決定 Z」等單因說法需要檢驗。
6. 涉及政治租金、市場報酬、監管護城河、制度套利、路徑依賴或可計算性。

### 不應觸發

- 單純查日期、定義或單一史實；
- 純粹道德表態，沒有要解釋制度結果；
- 只有一個案例且沒有時間、群體或制度上的變化可比較；
- 使用者只要翻譯、排版或摘要，沒有分析要求。

## 二、必要輸入

至少取得：

- **結果 Y**：到底要解釋什麼制度結果？
- **範圍**：哪些時期、地區、公司、群體或政策？
- **對照**：至少一個結果不同、時間不同或條件不同的案例。
- **證據**：可定位的文本、資料、訪談、法規或史料。
- **決策用途**：這個解釋會改變什麼判斷？

缺少對照時，不要假裝已做因果分析；先把輸出標為「單案例機制假說」。

## 三、標準八步程序

### Step 1：界定結果與移除測試

把抽象名詞改成可判定的制度結果，並問：

> 如果把候選制度 X 在思想上移除，Y 是否仍以近似方式發生或運作？

這是反事實式診斷，不是把 X 宣判成充分原因。

### Step 2：拆制度維度

至少檢查：

| 維度 | 必問問題 |
|---|---|
| 占有與控制 | 土地、資料、工具、平台、固定資本和產品由誰控制？ |
| 勞動與成員資格 | 自由契約、依附、外包、專業身分或家計義務？ |
| 市場與需求 | 誰能進入市場、接近顧客、定價或排除競爭者？ |
| 技術與基礎設施 | 技術改變了哪些可行選項？誰負擔固定成本？ |
| 法律與行政 | 權利、契約和政策後果能否被預計？ |
| 組織邊界 | 家計／企業、國家／公司、平台／補充者如何分離？ |
| 核算與資訊 | 成本、收益、責任與風險能否被持續比較？ |
| 生活取向 | 行動者追求利潤、身分、生計、安全、使命或救贖？ |

### Step 3：建立並列類型

先用類型描述結構，不預設單線階段。每個類型必須寫出比較維度，不能只貼「封建」「現代」「官僚」等標籤。

### Step 4：重建行動者機制

對每類行動者回答：

1. 他控制什麼資源？
2. 他想維持或改變什麼？
3. 新條件如何改變他的選項與報酬？
4. 他的行動造成哪些非預期後果？

### Step 5：用對照隔離條件

優先找：

- 相同刺激、不同結果；
- 不同刺激、相同結果；
- 制度改變前後；
- 成功案例與反例；
- 行動者原意與總體結果不一致。

### Step 6：標注因果角色

每個因素必須標為：`必要前提`、`促進條件`、`阻礙`、`傳導機制`、`可利用機會`、`回饋`或`非預期後果`。不知道就標 `待辨識`，不要一律寫成「原因」。

### Step 7：建立條件合取與回饋

輸出至少一條機制鏈：

```text
制度條件 A × 行動者能力 B
→ 機會／限制 C
→ 行動 D
→ 結果 Y
→ 回饋到 A 或 B
```

並指出哪個條件是所有案例共有的背景常數；**常數不能解釋案例間的變異**。

### Step 8：來源審計與決策翻譯

每項結論標成：

- `[直接證據]`
- `[由案例推導]`
- `[跨著作／跨理論補充]`
- `[當代延伸]`
- `[待驗證]`

最後才回答 so what：哪些制度變數可由使用者選擇、規避或利用？若使用者一側沒有槓桿，明說槓桿位於誰手上。

## 四、強制輸出

完整模式至少包含：

1. 一句話結果定義；
2. 制度維度矩陣；
3. 行動者—資源—目標表；
4. 至少一組對照或反例；
5. 因果角色表；
6. 一條條件合取／回饋鏈；
7. 最強替代解釋與何種觀察會削弱主張；
8. 來源層級；
9. 對決策的影響。

快速模式可縮成六問：

1. 要解釋的結果是什麼？
2. 誰控制關鍵資源與規則？
3. 誰的目標不是利潤最大化？
4. 相同刺激在哪個對照案例產生不同結果？
5. 各因素扮演什麼因果角色？
6. 哪個證據能推翻目前解釋？

## 五、各 Skill 的調用方式

| Skill | 何時調用 | 必須增加的輸出 |
|---|---|---|
| `learning-notes` | 制度、產業演化、組織史、國家—市場、技術與社會秩序主題 | 制度矩陣、對照案例、因果角色、來源標籤 |
| `concept-tutor` | 解釋可計算性、政治租金、制度套利、路徑依賴等 | 定義之外，補行動者、機制、對照與近親概念 |
| `advisor-dialogue` | 使用者有單一制度／歷史因果問題要壓力測試 | 一次一問，依序逼出結果、控制權、對照、因果角色與可否證條件 |
| `problem-finding` | 尋找制度性或跨層級研究問題 | P2 依機制群集；P3 加入「同刺激異結果」與制度變異 gate |
| `so-what` | 分析結論主詞是制度、產業或市場 | 把結構歸因翻成可選變數，同時保留不可控邊界 |

## 六、常見失敗

- **因素清單冒充解釋**：列了技術、文化、法律，卻沒有機制鏈。
- **單線階段論**：把並存、分岔的組織形式排成必然進步。
- **刺激決定論**：看到市場／AI／監管就直接預測同一結果。
- **把理念類型當現實或應然標準**：分類工具被拿來判決成功失敗。
- **把適當因果寫成充分原因**：忽略替代路徑與條件合取。
- **只有結構、沒有行動者**：說「制度造成」，卻沒說誰藉由什麼權力實現。
- **只有行動者、沒有制度**：把結果全歸因於努力、貪婪或文化性格。
- **跨書概念偷渡**：沒有標明本書、韋伯其他著作與現代作者推演的界線。

## 七、原典案例庫

- 03_第一篇_農業組織與權利分化：相同市場刺激、不同權利結果。
- 04_第二篇_工業礦業與生產組織：技術必須透過占有、固定資本、勞動和核算才改變組織。
- 05_第三篇_商業貨幣信用與企業形式：信用、風險、問責和企業邊界的共同演化。
- 06_第四篇_現代資本主義的條件合取：多項條件如何形成自我再生產的支配秩序。
- 08_Antigravity分析核查表：方法論、概念歸屬與硬錯的紅隊示範。
