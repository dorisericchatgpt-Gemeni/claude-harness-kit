# 行為機制鑑別矩陣

**所屬分支：** 00_教學大綱總覽  
**使用程序：** [[02_異常驅動的理論壓力測試方法]] ｜ **量測檢查：** [[../15_Observable_Method_Fit|Observable–Method Fit]]

> [!important] 使用原則
> 同一現象與多個機制一致時，不要投票選最熟悉的 bias。改變一個能讓候選機制產生**不同方向預測**的因素，並保持 final outcome、誘因、交易成本與資訊條件盡量不變。

## 核心矩陣

| 機制／benchmark | 關鍵操弄 | 主要 observable | 支持性模式 | 會削弱／推翻什麼 |
|---|---|---|---|---|
| Winner’s curse／conditional-information neglect | 固定價值分布，改競標者數、公開他人訊號、提供條件化提示 | bid、得標後利潤、對人數反應 | 人數增加仍不降反升；提示後改善 | 若正確條件化且競標者愈多愈保守，削弱 curse |
| Overconfidence | 分開量估值誤差、信心區間與得標效用 | calibration、bid residual | 過窄信心預測額外出價 | 控制資訊推理後，confidence 不再預測 |
| Reciprocal cooperation | fixed partner vs stranger rematching、one-shot vs repeated | contribution、punishment | 只在可回報互動強 | 陌生 one-shot 仍高合作，排除純直接互惠 |
| Altruism／warm glow／theft aversion | 改受益者、可見性、失物是否有人格線索 | 給予、歸還、排擠率 | 對他人利益／自我形象操弄有系統反應 | 完全由未來回報或監督解釋 |
| Fairness vs rejection fear | Ultimatum → Dictator；改 responder veto | offer、最低接受額 | 移除 veto 後仍正額，但下降 | 移除 veto 後歸零，較支持策略恐懼 |
| Intention／appearance of fairness | 固定 outcome，改可選集合、隱藏資訊 | 接受、懲罰、offer | 同結果因意圖／可見公平不同而變 | 只由最終分配預測 |
| Endowment／giving-up pain | Seller vs Chooser vs Buyer；隨機 ownership | WTA、WTP、choice | Seller 高於 Chooser≈Buyer | 三組相同或 ownership 不影響 |
| Status quo inertia | 改 default，另給主動確認、注意力提醒 | 留在 default、切換 | 提醒後仍有方向性 loss pattern | 注意力／成本清除後完全消失 |
| Loss aversion | 固定 final wealth，只改 gain/loss coding；估參照點兩側 | choice、effort、WTA/WTP | 參照點有 kink、等額 loss 影響較大 | 兩側反應對稱；只推翻該 reference specification |
| Total-wealth curvature | 改 stake/wealth ratio、跨財富水準重做 | 小賭局選擇 | 小 stake 應近似線性 | 持續小額拒絕加合理大額接受，形成 Rabin 壓力 |
| Narrow bracketing | 同賭局分開 vs 合併呈現 | choice reversal、dominance | 合併後因 diversification／dominance 翻轉 | 合併與分開一致 |
| Probability weighting | 固定 outcomes，密集改 0／小機率／中間／1 | certainty equivalent | 0、1 附近非線性特別強 | decision weights 接近機率 |
| Present bias | 同 delay gap 整組移近／移遠現在 | preference reversal、\(\beta\) | 接近 now 才反轉 | 無 now boundary、\(\beta≈1\) |
| Hyperbolic vs beta-delta | 多個近端與遠端 delay | discount curve | 連續下降 vs now 跳躍後指數 | 單一 now/later 題不能區分 |
| Savoring／dread | 固定消費日，改可期待／擔憂資訊期間 | preferred timing、WTP | 好事願延、壞事願提早 | anticipation 操弄無效 |
| Mental accounts | 等額 shock 改 label/source/destination/realization；跨品類 placebo | MPC、品類升級、帳戶移轉 | 支出集中在被標記帳戶 | 各來源 MPC 相同、placebo 同幅 |
| External liquidity constraint | 提供現金／信用、量既有額度與 co-holding | consumption smoothing、債務 | 提供流動性後完全平滑 | 有資源仍依 label 不平滑，支持 self-imposed account |
| Scale compatibility | choice vs pricing；眼動／注意力 | choice–price reversal | pricing 增加 payoff attention | response mode 不影響權重 |
| Projection bias | 決策時狀態隨機化或用偏離當地常態的短期 shock | 未來選擇、預測誤差 | 當下狀態影響遠期選擇 | 狀態控制後無效 |
| Peak/end／duration neglect | 同總痛苦、改尾段與 duration | remembered utility、repeat choice | 較長但尾段較輕被偏好 | 評價按痛苦積分單調 |
| Adaptation／focusing illusion | 比 forecast 與 longitudinal experience；分散注意力 | forecast error、experienced utility | 高估單一改變的長期影響 | 預測校準且追蹤一致 |
| Risk premium vs mispricing | 明示並量測候選 factor、容量與成本 | alpha、factor loading、out-of-sample return | 報酬由事前風險暴露預測 | 無風險差異仍存在，risk rescue 失敗 |
| Identical-payoff mispricing | 建立 state-by-state payoff identity | 同步價格比 | 相同 payoff 長期顯著不同價 | 現金流、權利或費用其實不同 |
| Short-sale constraint | 借券可得性、fee、float、制度變更 | premium、借券量、收斂 | constraint 鬆綁後價差縮 | 借券容易仍長期偏離 |
| Noise-trader／funding risk | 量 margin、redemption、spread widening、終止日 | 強平、資金流、價差 | 錯價擴大時理性資金被撤 | 風險可完全鎖定且無期限壓力 |

## 最小設計語法

把候選機制寫成：

```text
若 H 為主機制，
在只改變 X、保持 Y/Z 不變時，
O 應由 a 變成 b；
若觀察 c，則 H 在此 domain 被削弱。
```

例：

```text
若 gasoline mental account 為主機制，
等額油價下降應提高 gasoline 內部品質，
但不提高 milk／orange-juice 品質；
若三品類同幅升級，較像一般所得效果。
```

## Factorized 設計

對風險、時間與消費問題，可從：

```text
sign × reference point × bracket × timing × label/source × liquidity
```

挑最少能區分候選機制的因素。若同一受試者容易識破關聯，使用 between-subject；若個體異質性是主要噪音，考慮 within-subject 並 counterbalance。

## Observable 警告

- choice、pricing、WTP/WTA、forecast、experienced utility 不是同一量；
- contribution rate 不是 free-riding rate；
- price deviation 不是 arbitrage profit；
- 方向重現不是效果量相同；
- field association 不是心理過程；
- default adoption 不是 welfare improvement；
- 無法識別機制時，用「與 H 一致」，不用「H 導致」。

## Steelman 反方立場

Factorial design 可能因透明、人工與低 stakes 而改變自然行為；field data 又常缺乏乾淨操弄。沒有單一設計能同時最大化 internal 與 external validity。可行策略是 triangulation：lab 做機制分歧、field test 做現實重要性、樣本外資料做持續性；三者不必假裝是同一證據。

## Bloom 高階理解檢核

- **L4**：為一個 default effect 同時列 loss aversion、inertia、attention 三個預測。
- **L5**：何時 within-subject 提高識別，何時反而暴露研究目的？
- **L6**：從矩陣選三個機制，設計一個最小實驗使三者方向不同。
